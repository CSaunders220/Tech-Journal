## Defining a Variable

Defining a variable in Rust is different than in Java or in Python where there are two ways covered so far that I have learned. One way is to define it as a standard variable by using the code shown below and using the let command. For example:

```
let x = 2;
```

This code defines a variable named x with a value of two. In Rust you can cast a variable type just like in Java and statically assign that type to the variable like the example below.

```
let x: u32 = 2;
```

In this case, the variable x now is assigned a value of two but is also assigned the unsigned 32 bit integer type so this variable can now only values of this type unless otherwise told.&#x20;

There is also a way to define a global variable using the pub command and assigning it a name and a value like below.

```
pub y = 3;
```

Here, the variable is named y and this is a global public variable that can be accessed and referenced at any time in the code. I also learned that by adding the const tag to this variable that you can make the variable a global constant variable like below.

```
pub const y: i32 = 3;
```

Here, the variable y is not only a constant but also cast to a 32 bit signed integer.&#x20;

## Strings and Mutable Strings

In Rust, an object is not mutable or changeable unless otherwise explicitly stated in the definition of the variable. In the code block below I establish a mutable variable from the type String and save it as a mutable string and then in the next line print it by calling the variable in the code.&#x20;

```
let mut text :: String = String::from("Hello World!");
text
```

This value then gets changed to hold a value of "bye" by the provided function from the lesson as seen below. If called again, the value of the variable text would now be "bye".

```
pub fn mutates_value(value: &mut String) {
    *value = String::from("bye")
}
```

## Data Types

There are many data types in Rust and the table below contains all of the data types and their descriptions for further use and ease of reference.

| Data Type Indicator | Data Type                                                                                                                                |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| i8                  | Signed 8 bit integer                                                                                                                     |
| i16                 | Signed 16 bit integer                                                                                                                    |
| i32                 | Signed 32 bit integer                                                                                                                    |
| i64                 | Signed 64 bit integer                                                                                                                    |
| i128                | Signed 128 bit integer                                                                                                                   |
| u8                  | Unsigned 8 bit integer                                                                                                                   |
| u16                 | Unsigned 16 bit integer                                                                                                                  |
| u32                 | Unsigned 32 bit integer                                                                                                                  |
| u64                 | Unsigned 64 bit integer                                                                                                                  |
| u128                | Unsigned 128 bit integer                                                                                                                 |
| isize               | Signed integer of unknown size, used primarily for indexing                                                                              |
| usize               | Unsigned integer of unknown size, used primarily for indexing                                                                            |
| f32                 | 32 bit float variable used to store 32 bit decimal numbers                                                                               |
| f64                 | 64 bit float variable used to store 64 bit decimal numbers                                                                               |
| char                | characters used for storing a single characters like 'a'                                                                                 |
| bool                | Boolean, stores true or false                                                                                                            |
| \&str               | String slice, a view into a string typically used to store a part of a string, immutable. Can be created from a slice of another string. |
| String              | String type, used to store strings of variable length.                                                                                   |
| arr                 | Array, used to store a list of values of the same type.                                                                                  |
| tuple               | Tuple, used to store a list of values of varying types.                                                                                  |
| fn \<name>          | This declares a functions but functions can also be assigned like a data type in Rust. Used to reference a function and call it later.   |
| () or unit type     | Unit type, used to return nothing.                                                                                                       |
| ! or never type     | Never type, used to break the script / code out of the execution. Think panic button.                                                    |

The script below uses some of the data types above to establish variables, save them to a tuple, and then print it to the interface.&#x20;

```
pub fn data_types() -> (u8, f64, bool, char) {
    let number : u8 = 42;
    let floating : f64 = 3.14;
    let boolean : bool = false;
    let character : char = 'a';
    (number,floating,boolean,character)
}
```
